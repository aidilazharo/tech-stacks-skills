# SDLC Catalog 1.1.14

- React + SQLite baseline includes an interactive Qi-inspired component gallery alongside the developer startup dashboard and ATGV mark.
- The gallery demonstrates buttons, badges, cards/KPIs, form inputs, selects, tables, progress, accordions and confirmation dialogs.
- Respects keyboard tab navigation, reduced-motion and mobile layouts.
- Preserves existing application files: adoption by an existing project requires verified catalog migration, never an unconditional overwrite.
- Uses the independent Qi-inspired kit, not official or proprietary AIA Qi assets.
