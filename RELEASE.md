# ATGV SDLC Library v0.0.9

## Changes

- Replace Python 3.11-only hashlib.file_digest with bounded streaming SHA-256 compatible with macOS Python 3.9.
- Preserve checksum and asset verification, mismatch rejection, and release identity safeguards.
- Add regression coverage for empty, small and multi-chunk binary files without hashlib.file_digest.

## Verification

Targeted checksum and corruption-rejection checks passed on Python 3.13 with the newer file_digest API disabled in the compatibility test. The checksum code was parsed with Python 3.9 grammar. Full repository validation and execution on Python 3.9 remain to be verified; no release ZIP was generated by this source update.
