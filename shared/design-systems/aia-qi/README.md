# AIA Qi-informed UI/UX starter (provisional)

AIA Qi official landing page describes a reusable design language for consistency, efficiency and scalability. No official design token or component code was publicly supplied to this repository. **This directory is an original adaptation guide, not an official or certified AIA Qi library.**

Use for reviewable mockups. Obtain and replace provisional tokens with AIA-approved component specs before production. Do not use this directory to imply brand approval.

Source: https://design.aia.com/aia-qi-design-system

## Versioned local component catalogue (1.1.1)

This repository now includes the separately supplied **independent Qi-inspired AI UI kit v1.0.0** at `kit/`. The machine-readable inventory is `kit/ai/component-catalog.json` and the standalone examples, tokens, stylesheet and documentation live under that directory. The ATGV extension reads that inventory from the pinned GitHub `main` SHA and displays a generated, script-free local component catalogue in VS Code.

**Important:** This is not the official AIA Qi component library, and the included styles/tokens are not an endorsement or approval of AIA brand specifications. The original kit's MIT license and NOTICE are retained; enterprise use needs design-owner sign-off.
