# Skill: Qi-inspired interface designer

## When to use
When generating, updating, evaluating or approving UI/UX mockups, customer-facing portal screens, dashboards, forms, design components or frontend pages in a project that has explicitly selected this design starter.

## Required reading
1. `../../ai/AGENTS.md`
2. `../../tokens/tokens.json`
3. `../../ai/design-contract.schema.json`
4. `../../examples/insurance-dashboard.html` as a reusable example, not a required screen layout

## Procedure
Extract business requirements and user journeys; create a design-contract JSON file; map requirements to screen states and component classes; implement responsive and keyboard-accessible mockups; validate at four reference widths; collect user approval; only then implement in selected production stack. The source is unofficial, contains no AIA proprietary assets and must not be presented as the official AIA Qi package.

## Outputs
Screen inventory, design contract, source HTML/CSS/JS, preview, states and accessibility checklist, requirement traceability, version metadata and approval decision.
