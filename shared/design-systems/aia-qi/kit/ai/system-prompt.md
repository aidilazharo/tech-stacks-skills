No fake interactive controls, no invented user data represented as real, no unlicensed logo/font imports, and no hard-coded alternative color system. Review keyboard interactions, labels, dynamic status, error recovery, content hierarchy, responsiveness, contrast and reduced motion. Deliver functioning source code, preview, traceability, assumptions, and verification results.
