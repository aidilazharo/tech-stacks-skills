09 / Quick start

Use it like a Bootstrap starter

Copy the files into a web project. For AI workflows, load ai/AGENTS.md, tokens/tokens.json and the relevant example before generating screens.

<link rel="stylesheet" href="css/qi.css">

<main class="qi-container qi-page">
  <div class="qi-row">
    <section class="qi-col-12 qi-col-md-6 qi-card">
      <h1>Hello</h1>
      <button class="qi-btn qi-btn-primary">Continue</button>
    </section>
  </div>
</main>

<script src="js/qi.js"></script>

No install or build command needed. The NPM package metadata also lets you embed the kit in a larger project.
