# ATGV approved webview libraries

This package contains version-pinned CodeMirror 5.58.3, Quill, Frappe Gantt and SortableJS 1.15.7 browser resources. Each file is checksum-verified by ATGV before local caching or execution. Do not edit bundles in-place; publish a reviewed and independently tested release when updating binaries. The ATGV extension pins approved bundle hashes.

SortableJS 1.15.7 is used by Project Manager Kanban; it is optional and the ATGV controller uses native drag-and-drop when it is missing. Its MIT license and distribution provenance are included alongside the JavaScript asset.

These are optional webview UI libraries. Trusted Node.js validation code remains in the extension and is not loaded from the catalog.
