# ATGV approved webview libraries

This package contains version-pinned CodeMirror 5.58.3, Quill and Frappe Gantt browser resources. Each file is checksum-verified by ATGV before local caching or execution. Do not edit bundles in-place; publish a reviewed and independently tested release when updating binaries. The ATGV extension pins approved bundle hashes.

These are optional webview UI libraries. Trusted Node.js validation code remains in the extension and is not loaded from the catalog.
